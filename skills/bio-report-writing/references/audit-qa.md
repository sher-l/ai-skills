# 审核 QA（不进入客户正文）

从本地报告审核框架提炼的五个检查面：

1. **覆盖**：每个数据集、模块、分组、Figure/Table、关键数字、阴性和失败分析都有记录；
2. **事实**：数据库、URL、术语、翻译、样本数、单位、方向和统计标准正确；
3. **一致**：方法、正文、表格、图题、图注、文件名和发布树一致；
4. **代码衔接**：实际脚本、参数、配置、结果表和图件 provenance 可定位；
5. **证据**：高风险结论有结构化数值、原始/中间输出和适用边界，不以图片或一句话替代。

图件逐图记录渲染、标题实体、panel、轴/单位、图例、阈值、数值和文件。损坏、空白、截断或错项目图是阻断项；panel 与图注不匹配也是阻断项。视觉可读、语义自足和科学证据分别判定。

审核矩阵、错题集、机械检查日志和内部结论只用于 QA，不能复制到面向客户的报告。
