# 报告语料提炼索引

本文件保存从本地样本和审核结果提炼的写作模式，不复制客户报告正文。

## 正向组合

- 优秀报告样本：方法给出数据集、样本数、包版本、阈值和算法；结果给出数量、方向、
  Figure/Table 绑定；图注逐 panel 说明对象、轴、颜色和统计；
- 交付修正版样本：每个分析点固定为“输入 → 方法/阈值 → 结果 → 文件/下一步 → 限制”，
  用数量链和证据表收束结论；
- test55：每个源图一个完整 drawing，图题、整图和图注相邻，目标阅读器逐页检查。

## 必查反模式

复制项目身份、疾病名、路径或编号；方法/结果/图注的 TopN、样本数、方向或阈值不一致；
只交图片没有结构化表；训练集性能被写成泛化能力；关联、拟时序、虚拟 KO、对接或
MD 被写成因果/疗效；总结新增正文没有的结论；公司宣传页进入研究正文。

## 视觉回归

test54 的单一 composite PNG 被切成半幅/三幅，虽然几何比例检查通过，标题和轴仍跨页
断裂。正式规则因此检查源媒体与 drawing 的完整性、caption 邻接和渲染页面，而不是只
检查 hash、DPI 或 XML 是否存在图片。
