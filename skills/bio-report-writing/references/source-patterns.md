# 报告语料提炼索引

本文件保存从本地样本和审核结果提炼的**可迁移写法**，不复制客户报告正文，也不替代报告合同。

## 正向组合

- 成熟 Rmd/报告：方法给出数据集、样本数、包/资源版本、阈值和算法；结果给出数量、方向、统计量、
  Figure/Table 绑定；图注逐 panel 说明对象、轴、单位、颜色和统计。
- DEGs 交付：每个分析点固定为“范围 → 方法/阈值 → 结果 → 文件/下一步 → 限制”；结果预览表与完整业务
  文件分工；PNG/PDF 在输出表合并为一个逻辑图行；方向 Note 和末尾版本表由事实驱动。
- `test55` 视觉经验：每个源图一个完整 drawing，图题、整图和图注相邻；目标阅读器逐页检查比 hash/DPI
  更能发现分页和语义问题。
- 报告 coder 分工：固定 prose、表列、caption 和 Note 样式写进唯一模板；renderer 只绑定 typed slots，
  不让运行期语言模型临场改写。

## 必查反模式

复制项目身份、疾病名、路径或编号；方法/结果/图注的 TopN、样本数、方向或阈值不一致；只交图片没有结构化
表；训练集性能被写成泛化能力；关联、拟时序、虚拟 KO、对接或 MD 被写成因果/疗效；总结引入正文没有的
数字；把 RSS top-TF、regulon 基因和候选 TF-target 边混为同一证据层；公司宣传页进入研究正文。

## 视觉回归

历史案例中，单一 composite PNG 被切成半幅/三幅，虽然几何比例检查通过，标题和轴仍跨页断裂。正式规则
因此同时检查源媒体与 drawing 的完整性、caption 邻接、Note 位置、表头分页和最终渲染页面；不以单一 hash、
DPI 或 XML 存在性宣称通过。
