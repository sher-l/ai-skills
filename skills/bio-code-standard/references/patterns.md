# 代码模式摘要

## 保留的成熟模式

- 先用 `doc/source-review.md` 固定源码清单、官方定义和实际运行观察，再选择唯一 canonical source；
- 用显式 CLI 参数、配置相对路径和输入输出注释建立阶段边界；
- 用 `stopifnot`/显式断言检查 ID、方向、样本顺序和非退化条件；
- 同时保存 full 表、筛选表、边表/节点表和图件来源；
- 用统一绘图 helper 输出 PDF/PNG，并记录尺寸、字体和 renderer；
- 用 Rmd 或等价文档把参数、图件和 `sessionInfo` 绑定。

## 复核触发器

看到绝对路径、链式 `setwd`、平行脚本、无计数过滤、全局 warning 抑制、变量覆盖、默认图尺寸、静默错误恢复或未解析文本时，先记录影响，再按核心合同修复；出现频率不代表规范。

算法名相同不代表逻辑相同。复核实际调用、分支条件、输入表和输出表，报告只引用实际执行版本。
