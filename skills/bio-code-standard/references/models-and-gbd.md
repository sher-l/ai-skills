# MR、生存、机器学习与 GBD

## MR / mediation

记录 exposure、outcome、工具变量筛选、方向、敏感性方法、水平多效性和缺失状态。漏斗图对称、单次 mediation 或单一模型输出不能自动升级为无混杂、因果或临床结论。

## 生存与机器学习

记录时间单位、事件定义、删失、训练/验证边界、特征选择、seed、超参数和性能区间。AUC、校准、DCA 和 C-index 按数据集和验证层级分别报告；单个训练集高分不等于泛化能力。

## GBD 与指标语义

对 Incidence、Prevalence、DALY、ASDR 等指标建立名称—中文—单位—公式映射，并在运行前断言。EAPC、log 变换、bootstrap 和趋势方向要记录实际公式与非正值处理。标签不能靠人工直觉互换。

## 高风险推断

虚拟 KO、分子对接、MD、药物预测和网络扰动输出“计算提示/候选/模型结果”，并列出输入、参数、原始或结构化输出和限制。它们不单独支持真实因果、疗效、安全性或稳定结合声明。
